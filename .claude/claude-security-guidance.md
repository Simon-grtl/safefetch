# SafeFetch — project security rules (for security-guidance reviews)

Review every change against these rules. Any violation is a blocker.

## Files from the network
1. Every name from `Content-Disposition` or the URL goes through `sanitize::sanitize_filename` (NFKC, last path component only, control/bidi/invisible characters removed, `<>:"|?*` replaced, no leading/trailing dots or spaces, Windows reserved names prefixed, deceptive double extensions rewritten, length-limited).
2. Downloads are written **only** into the quarantine folder, under `<32 random hex>.quarantine`, created with `create_new` and mode 0600; Mark-of-the-Web (Windows) / `com.apple.quarantine` (macOS) applied.
3. SafeFetch never opens, previews, extracts or executes a downloaded file. Only hashing and streaming to clamd are allowed.
4. Delivery uses `delivery::deliver` (hard link + unlink, no-clobber, target must be a direct child of the destination). Never `fs::rename` onto an existing name, never `fs::copy` from quarantine.
5. Quarantine ids coming from anywhere must pass `quarantine::valid_id` (exactly 32 lowercase hex). The UI only ever sends numeric job ids.

## Network
6. HTTP clients are built with `net::build_client`: no automatic redirects, no transparent decompression (`Accept-Encoding: identity`), connect + idle timeouts, rustls only.
7. Each redirect hop goes through `net::check_redirect` (http/https only, no https→http, no public→private/loopback, no credentials) and the hop limit.
8. When the user typed a public URL, DNS goes through `PublicOnlyResolver`.
9. Announced size (Content-Length / Content-Range) is enforced against bytes received; max size and free disk space are checked before and during the download.
10. URLs shown or logged go through `net::display_url` (no query string, no userinfo).

## Verdict
11. A file is **Clean** only if at least one local engine completed AND no engine/VirusTotal signal says otherwise (`verdict::decide`). Any limit, truncation, encryption, error or missing engine ⇒ Not analyzed.
12. clamscan always runs with raised limits, `--alert-exceeds-max=yes`, `--alert-encrypted=yes` and `--debug` (truncation markers); files ≥ 2 GiB are Not analyzed (libclamav limit). clamd is used only when its clamd.conf proves `AlertExceedsMax yes`, `AlertEncrypted yes`, `MaxFileSize ≥ 2047M` and sufficient `StreamMaxLength`.
13. Thresholds come from settings; never hard-code new ones.

## Secrets and privacy
14. The VirusTotal key lives only in the OS keychain (`SecretStore`), is wrapped in `SecretString`, sent with a sensitive header, and is never logged, formatted, serialized or returned to the UI (write-only).
15. Never send a file to VirusTotal automatically. `VtClient::upload_file` may only be reached from `Engine::upload_to_virustotal`, triggered by a double-confirmed UI action (`confirmed: true`).
16. History stores URL **hashes**, never plain URLs.

## Tauri / UI
17. No `shell`, `fs`, `http`, `process`, `dialog`, `opener` or `updater` permission in `src-tauri/capabilities/`. Only `allow-<command>` permissions generated by `build.rs` plus `core:event:allow-listen/unlisten`.
18. New commands: typed arguments only; never accept a path, an arbitrary URL to open, a program path or a command line from the webview. Paths come from the native picker; URLs to open are rebuilt and checked in Rust.
19. Executable paths (clamscan, freshclam, clamd) are not editable from the UI.
20. CSP stays strict (`'self'` only, no `unsafe-inline`/`unsafe-eval`, no remote origins). The UI uses `textContent`/DOM nodes, never `innerHTML`/`eval`.
21. `tauri-plugin-connector` only under `cfg(all(debug_assertions, feature = "dev-connector"))`; a `compile_error!` forbids it in release; CI checks the dependency tree and the binary.

## Processes
22. External programs are spawned with `Command::new(<absolute path>)` and an argument vector (never through a shell), with `--` before file paths, stdin closed, `kill_on_drop`, a timeout and bounded output capture.

## Dependencies
23. New crates need a justification in DECISIONS.md, must pass `cargo deny check` and `cargo audit`; no OpenSSL/native-tls, no git dependencies.
